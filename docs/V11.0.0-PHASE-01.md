# ANJANA AI V11.0.0 — Phase 01 Foundation

## Implemented in this patch
- Hybrid cloud provider priority is Gemini -> OpenAI -> Ollama.
- Explicit Gemini, OpenAI and Ollama modes remain available.
- Legacy `AI_MODE` is recognized when `AI_PROVIDER` is not set.
- Ollama default model is Qwen2.5:3b.
- Backend/core/package metadata and PWA cache version are updated to 11.0.0.
- New browser chat-history key prevents V10 messages from being automatically restored. V10 history is preserved, not deleted.
- `.env.example` documents variable names only.

## Not completed in Phase 01
- Unified tool/function router and module execution.
- Avatar + Chat-only UI cleanup.
- Persistent cross-device memory.
- Vision, research, document, image/video/audio/3D generation services.
- Real Render, Gemini, OpenAI, Ollama and LiveAvatar end-to-end verification.

## Deployment caution
Existing Render Environment values are not modified by this source patch. Do not change production secrets without checking the currently deployed variable mapping.
