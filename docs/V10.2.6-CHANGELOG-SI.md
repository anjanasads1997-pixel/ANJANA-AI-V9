## වෙනස්කම්
- OpenAI HTTP 503 ඇතුළු තාවකාලික දෝෂ සඳහා එක් වරක් නැවත උත්සාහ කිරීම.
- Provider වෙතින් ලැබෙන HTTP තත්ත්වය, error code/message සහ request ID ආරක්ෂිතව diagnostic ලෙස පෙන්වීම.
- OpenAI Base URL එක නිවැරදි කිරීම සහ HTTPS validation.
- Hybrid mode හි OpenAI, Gemini, Ollama අසාර්ථක වීමේ හේතු එකතු කර පෙන්වීම.
- API key එක සකසා තිබීම සහ සත්‍ය API සම්බන්ධතාවය සාර්ථක වීම වෙන වෙනම පෙන්වීම.
- Browser cache සහ service worker version යාවත්කාලීන කිරීම.

## Render Environment
- AI_PROVIDER=hybrid
- OPENAI_BASE_URL=https://api.openai.com/v1
- OPENAI_MODEL=gpt-4.1-mini
- OPENAI_API_KEY=ඔබගේ වලංගු OpenAI API key

- LiveAvatar සඳහා ඔබගේ ගිණුමට Live mode අවසරය තිබේ නම් පමණක් LIVEAVATAR_SANDBOX=false භාවිත කරන්න.
