# ANJANA AI V10.4.0 — Full-Screen Live Avatar Interface

## ප්‍රධාන වෙනස්කම්
- පැරණි Dashboard layout එක වෙනුවට reference image එකට ගැළපෙන Full-Screen Avatar + Chat layout එකක්.
- Desktop: වම් පැත්තේ විශාල portrait/live video; දකුණු පැත්තේ full-height chat.
- Mobile: ඉහළ portrait panel සහ පහළ chat panel ලෙස responsive layout.
- LiveAvatar video element එක විශාල portrait frame එක තුළට ගෙන ගොස් session connect වූ විට fallback portrait වෙනුවට වීඩියෝව පෙන්වයි.
- Chat composer එකට attachment trigger, voice input සහ send controls.
- Account, Hybrid/Offline/Live engine diagnostics, camera, learning සහ tools පහසුකම් ඉවත් නොකර collapsible Settings/Tools කොටසකට ගෙන ගියා.
- පවතින backend endpoints, auth IDs සහ app JS control IDs ආරක්ෂා කර ඇත.

## සටහන
Static portrait එක live video නොවේ. සැබෑ animated avatar සඳහා Render Environment තුළ නිවැරදි LiveAvatar API key සහ Avatar ID තිබිය යුතු අතර Start Live Avatar බොත්තම ඔබා session එක සාර්ථකව සම්බන්ධ කළ යුතුය.
