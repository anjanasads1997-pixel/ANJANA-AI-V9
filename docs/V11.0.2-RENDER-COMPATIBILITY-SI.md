# ANJANA AI V11.0.3 — Render සැකසුම් ගැළපීම

## දැනට පෙන්වා ඇති Render සැකසුම
- `AI_PROVIDER=hybrid` — Gemini → OpenAI backup → Ollama.
- `GEMINI_API_KEY` සහ `GEMINI_MODEL=gemini-2.5-flash` — ප්‍රධාන Gemini සම්බන්ධතාව.
- `BACKUP_OPENAI_API_KEY`, `BACKUP_OPENAI_BASE_URL`, `BACKUP_OPENAI_MODEL` — OpenAI backup.
- පැරණි `OPENAI_BASE_URL` Google `googleapis.com` endpoint එකක් නම්, `OPENAI_API_KEY` / `OPENAI_MODEL` Gemini legacy mapping ලෙස හඳුනාගනී; OpenAI සඳහා `BACKUP_OPENAI_*` භාවිත කරයි.
- `LIVEAVATAR_API_KEY`, `LIVEAVATAR_AVATAR_ID`, `LIVEAVATAR_MODE=LITE`, `LIVEAVATAR_SANDBOX=false` — LiveAvatar LITE.
- `TAVILY_API_KEY` — දැන් authenticated `/api/research/search` endpoint හරහා Web Research.

## HeyGen සහ LiveAvatar
`HEYGEN_API_KEY` සහ `LIVEAVATAR_API_KEY` වෙනස් සේවා සඳහා වූ වෙනස් credentials වේ. මෙම build එකේ avatar streaming සඳහා නිල LiveAvatar LITE API/SDK භාවිත වේ. ඒ නිසා `HEYGEN_API_KEY` එක LiveAvatar key එක වෙනුවට භාවිත නොකරයි.

## තවමත් source එකෙන් භාවිත නොවන Render variables
Screenshot එකේ `ANJANA_ACCESS...` සහ `ANJANA_OWNER_...` ලෙස කැපී පෙනෙන custom variable නාම සම්පූර්ණයෙන් කියවිය නොහැකි අතර V11.0.3 හි authentication code ඒවා භාවිත නොකරයි. ඒවායේ අර්ථය තහවුරු නොකර login/owner credentials ලෙස අනුමාන කර භාවිත නොකරන්න. Render තුළ තිබෙන අගයන් වෙනස් නොකර තබන්න.

## Research API
- `GET /api/research/status` — login අවශ්‍යයි; Tavily key තිබේද පමණක් පෙන්වයි.
- `POST /api/research/search` — login අවශ්‍යයි; JSON body: `{ "query": "..." }`; උපරිම ප්‍රතිඵල 5ක්.
- Tavily key server-side පමණක් පවතී. Browser වෙත key එක යවන්නේ නැත.

## Deploy කිරීම
1. ZIP එක GitHub වෙත upload කරන්න.
2. Render හි පවතින Environment Variables මකා නොදමන්න.
3. `TAVILY_API_KEY` සහ අවශ්‍ය `HEYGEN_API_KEY` පමණක් දැනටමත් තිබේ නම් ඒවා එලෙසම තබන්න.
4. Deploy පසු `/api/health` සහ login කිරීමෙන් පසු `/api/research/status` පරීක්ෂා කරන්න.
5. සැබෑ API request එකක් සාර්ථක වීම තහවුරු කිරීමට `/api/research/search` පරීක්ෂා කරන්න.

API key අගයන් ZIP, GitHub, browser හෝ chat තුළ ඇතුළත් කර නැත.
