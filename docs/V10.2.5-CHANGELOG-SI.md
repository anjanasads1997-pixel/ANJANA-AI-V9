# ANJANA AI V10.2.5 — දෝෂ හඳුනාගැනීම සහ සම්බන්ධතා නිවැරදි කිරීම්

නිර්මාණකරු: Anjana Sandakelum

## වෙනස්කම්
- OpenAI වෙත සෘජු, authenticated connection test එකක් `/api/ai/test` මඟින් එක් කළා.
- `/api/ai/status` තත්ත්වය UI හි පෙන්වයි: version, provider mode, OpenAI key configured ද, Gemini configured ද, Ollama available ද. Key validity තහවුරු කිරීමට Test OpenAI භාවිත කරන්න.
- Backend අසාර්ථක වූ විට සහ Offline model එක load කර නොමැති විට ව්‍යාජ canned පිළිතුරක් වෙනුවට සැබෑ දෝෂය Chat තුළ පෙන්වයි.
- LiveAvatar සඳහා ගිණුමට අයත් නිශ්චිත Avatar ID එක Render Environment තුළ අනිවාර්ය කළා.
- Service Worker cache version සහ server version යාවත්කාලීන කළා.

## Render Environment
- `AI_PROVIDER=hybrid`
- `OPENAI_API_KEY` = ඔබගේ OpenAI API key (රහසිගතව තබන්න)
- `OPENAI_BASE_URL=https://api.openai.com/v1`
- `OPENAI_MODEL=gpt-4.1-mini`
- `LIVEAVATAR_SANDBOX=false` (Live mode අවසරය ඇති ගිණුමකට පමණි)
- `LIVEAVATAR_AVATAR_ID` = ඔබගේ ගිණුමට අයත් සහාය දක්වන Avatar ID

## සීමා
OpenAI key වලංගුද, quota තිබේද, LiveAvatar account permissions හෝ Avatar eligibility තිබේද යන්න Render/Provider ගිණුමෙන්ම තහවුරු කළ යුතුය. Offline model එකේ Android browser/device compatibility එක දුරස්ථව සහතික කළ නොහැක.
