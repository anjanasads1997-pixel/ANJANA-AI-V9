## Deploy පසු පරීක්ෂාව
1. ANJANA AI වෙත ඔබගේ account එකෙන් Login වන්න.
2. `Test AI Engines (Gemini + OpenAI + Ollama)` ඔබන්න.
3. Gemini හෝ OpenAI එකක් `CONNECTED` ලෙස පෙන්විය යුතුයි. Ollama Render හි `127.0.0.1` වෙත යොමු වී ඇත්නම් එය සාමාන්‍යයෙන් `FAILED` වේ; Render container එකේ local Ollama service එකක් වෙනම සකසා නොමැති නම් මෙය expected.
4. `සජීවී Avatar ආරම්භ කරන්න` ඔබා LiveAvatar status message එක බලන්න. `LIVEAVATAR_API_KEY`, `LIVEAVATAR_AVATAR_ID`, account mode/permissions සහ quota එක නිවැරදි විය යුතුයි.

සැබෑ provider credentials සහ Render account access නොමැතිව live API connection එකක් මෙහිදී තහවුරු කළ නොහැක.
