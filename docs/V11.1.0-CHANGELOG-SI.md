- API 401/403 authentication failures offline fallback මඟින් සඟවා නොදමයි.
- `.env.example` හි Gemini, OpenAI, Ollama, Brain encryption, LiveAvatar, TTS සහ Tavily සැකසුම් වෙන් කර ඇත.
