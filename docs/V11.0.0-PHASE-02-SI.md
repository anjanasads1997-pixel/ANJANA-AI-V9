# ANJANA AI V11.0.0 — Phase 02
## Avatar + Chat Only Interface

### ක්‍රියාත්මක කළ වෙනස්කම්
- Desktop layout එකේ Avatar සහ Chat ප්‍රධාන workspace දෙක ලෙස පෙන්වයි.
- Mobile layout එකේ Avatar ඉහළින් සහ Chat පහළින් responsive ලෙස පෙන්වයි.
- පරණ Dashboard/Tools/AI mode tabs සහ settings panels දෘශ්‍යයෙන් සඟවා ඇත; ඒවායේ runtime DOM dependencies ඉවත් කර නැත.
- Login/Register පහසුකම header account control එකකින් විවෘත වන compact dialog එකකට ගෙන ඇත.
- Chat composer තුළ text, voice input සහ file attachment controls පවතී.
- New Chat සහ History controls එක් කර ඇත.
- Local chat history එක named sessions ලෙස සුරකින අතර උපරිම sessions 50ක් සහ session එකකට messages 300ක් සීමා කරයි.
- පැරණි single-thread V11 history එක පළමු load එකේදී session එකකට migrate කරයි.
- පවතින avatar image සහ LiveAvatar DOM hooks වෙනස් කර නැත.
