# ANJANA AI V11.0.0 — Phase 03
## Unified AI Brain Foundation

### Implemented
- `UnifiedBrain` is now the orchestration entry point for authenticated `/api/chat` requests.
- Gemini -> OpenAI -> Ollama provider priority remains in the existing provider router.
- The authenticated user's conversation ID is validated and used to isolate server-side context.
- Context is sent to Gemini, OpenAI-compatible and Ollama adapters (last 12 messages are included).
- Server-side context is encrypted with AES-256-GCM and stored in `DATA_DIR/brain-context.json` when `BRAIN_ENCRYPTION_KEY` is configured; writes use an atomic temp file with restrictive permissions. Without that key, context remains in process memory and is not written as plaintext.
- Context retention is bounded: default 40 conversations and 24 messages per conversation; each message is capped at 8,000 characters.
- Added an allowlisted read-only tool registry (`list_available_modules`, `get_runtime_status`).
- Permission policy denies unknown actions by default. Sensitive action classes (memory/file writes, external sharing, financial actions, device/security controls, account changes and deletion) require explicit confirmation and are not executable by this phase.
- Added `/api/brain/status` and authenticated `/api/brain/tools` endpoints.
- Health response now includes Unified Brain status without exposing provider keys.
- Frontend sends its existing active chat session ID to the backend; service-worker cache was bumped.

### Not included / external dependencies
- This phase does not implement model-native function calling; tools are a constrained server-side registry and status endpoint.
- It does not yet implement long-term semantic memory, embeddings/vector search, file-system tool execution, browser research, image/video/audio generation, or device control.
- For persistent encrypted memory, set a strong random `BRAIN_ENCRYPTION_KEY` in Render Environment and mount a persistent disk at `DATA_DIR`. Keep the key backed up securely; losing it makes existing encrypted context unreadable.
- No live Gemini/OpenAI/Ollama API call or Render deployment was performed in this build.

### Validation
- Unit tests cover context isolation, retention, persistence, provider context adapters, read-only tool allowlist and permission defaults.
- Run `npm test` after applying this patch.
