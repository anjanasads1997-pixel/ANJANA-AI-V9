## වෙනස්කම්
- V11.1.0 ව්‍යාපෘතියේ සියලු මුල් ගොනු පිටපතකින් ඉදිරියට ගෙන ගොස් ඇත; Core, Brain, Authentication, පැරණි chat history සහ LiveAvatar ගොනු ඉවත් කර නැත.
- Tablet සහ mobile browser වල desktop-width scaling නිසා පටු columns දෙකක් පෙන්වීම වැළැක්වීමට 1024px දක්වා single-column workspace එකක් එක් කර ඇත.
- Avatar සහ chat panel උස, scrolling සහ composer ඉඩ වැඩිදියුණු කර ඇත.
- Gemini model එකක් 404 / model-not-found / unavailable ප්‍රතිචාරයක් ලබාදුනහොත් පමණක් `GEMINI_FALLBACK_MODEL` මඟින් දෙවන උත්සාහයක් කරයි.
- Gemini model defaults සහ fallback දෙකම `gemini-3.8-flash` ලෙස සකසා ඇත. Render හි පැරණි `GEMINI_MODEL` environment variable එකක් තිබේ නම් එය Render Dashboard එකෙන් යාවත්කාලීන කළ යුතුය.
- API keys හෝ credentials ZIP එකට ඇතුළත් කර නැත.
