# ANJANA AI V10.2.3 — සිංහල වෙනස්කම් සටහන

## ප්‍රධාන වෙනස්කම්

- OpenAI ගෙවීම් සහිත API Engine එක `openai`, `cloud`, සහ `hybrid` modes තුළ පළමු ප්‍රමුඛතාවට පත් කළා.
- OpenAI අසාර්ථක වුවහොත් Gemini fallback එක උත්සාහ කරයි; එයත් අසාර්ථක නම් Ollama local fallback එක උත්සාහ කරයි.
- Render හි දැනට භාවිත වන `BACKUP_OPENAI_*` Environment Variable නම් පසුගැළපීම සඳහා තබා ඇත.
- `OPENAI_API_KEY` යනු දැනට Gemini-compatible endpoint එකට භාවිත වන නිසා එය OpenAI paid key ලෙස වැරදියට හඳුනා නොගනී.
- TTS readiness පරීක්ෂාව OpenAI TTS සඳහා අදාළ key variables පමණක් භාවිත කරයි.
- ප්‍රධාන UI හි නිර්මාණකරු ලෙස **Anjana Sandakelum** සිංහලෙන් සහ ඉංග්‍රීසියෙන් දක්වයි.
- Version අංකය 10.2.3 ලෙස යාවත්කාලීන කළා.

## Render සැකසුම්

- `AI_PROVIDER=openai` ලෙස තබන්න. `cloud` හෝ `hybrid` යන අගයන් ද භාවිත කළ හැක.
- `BACKUP_OPENAI_API_KEY` තුළ ඔබගේ OpenAI Platform API key එක තිබිය යුතුය. නම පැරණි වුවත් මෙම ව්‍යාපෘතියේ එය OpenAI primary key ලෙස භාවිත වේ.
- `BACKUP_OPENAI_BASE_URL=https://api.openai.com/v1` විය යුතුය.
- `BACKUP_OPENAI_MODEL` තුළ ඔබගේ OpenAI API account එකට අවසර ඇති model ID එක භාවිත කරන්න.
- `OPENAI_API_KEY` සහ `OPENAI_BASE_URL` යන පැරණි variables Gemini-compatible fallback-д зориулагдсан хэв පවතී.
