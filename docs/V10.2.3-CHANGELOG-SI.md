# ANJANA AI V10.2.3 — වෙනස්කම්

## ප්‍රධාන AI Engine අනුපිළිවෙළ වෙනස් කිරීම
- OpenAI දැන් ප්‍රධාන paid cloud AI Engine එකයි.
- OpenAI අසාර්ථක වූ විට Gemini දෙවන cloud AI Engine ලෙස උත්සාහ කරයි.
- Cloud AI දෙකම අසාර්ථක නම් Ollama local/offline Engine එක භාවිත කරයි.
- `AI_PROVIDER=openai`, `gemini`, `ollama` මඟින් අවශ්‍ය Engine එක බලහත්කාරයෙන් තෝරාගත හැක.

## Environment සැකසුම්
- `OPENAI_API_KEY` යනු OpenAI API key එකයි.
- `OPENAI_BASE_URL` default අගය `https://api.openai.com/v1` වේ.
- `OPENAI_MODEL` default අගය `gpt-4.1-mini` වේ.
- Gemini සඳහා වෙනම `GEMINI_API_KEY` සහ `GEMINI_MODEL` භාවිත කරයි.
- Ollama සඳහා `OLLAMA_BASE_URL` සහ `OLLAMA_MODEL` භාවිත කරයි.
- පැරණි Render deployment migration පහසු කිරීම සඳහා `BACKUP_OPENAI_*` aliases තබා ඇත.
